# Service Limiter

Analyze and limit resources for Windows and Linux services.

## Features
- Cross-platform (Windows, Linux)
- x64 compatible
- CLI for both platforms
- TUI with menu for Linux
- Resource profiling and limiting (CPU, memory, IO)
- Policy-based configuration generation
- Human-in-the-loop for critical changes
- Least-privilege design

## Installation
See [USER_GUIDE.md](USER_GUIDE.md) for detailed instructions.

## Usage
```bash
# CLI example
service-limiter analyze --profile web-server
```
